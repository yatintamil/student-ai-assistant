# Student AI Assistant

An AI-powered student productivity application built with Flutter and Firebase.

## Vision

Student AI Assistant helps students:

- Plan their day intelligently
- Manage tasks and habits
- Prepare for exams
- Track goals
- Improve consistency
- Receive personalized AI coaching

Unlike a traditional to-do app, the AI understands the user's schedule, goals, deadlines, habits, and progress to generate actionable recommendations.

## Tech Stack
